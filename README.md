## 실행
Windows x64 / Node.js 24 LTS / npm 11.
프로젝트 루트 C:\Users\ubob_kjm\Desktop\JM\zaggas에서 실행합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 http://localhost:3000 을 확인합니다.

```powershell
npm.cmd run lint
npm.cmd run build
npm.cmd run start
```

PowerShell 실행 정책을 변경할 필요는 없습니다.
GitHub origin은 https://github.com/kjm77171/zaggas.git 이며 기존 main 이력을 보존합니다. Supabase는 연결되지 않았습니다. 개인 Git local 이메일 설정 및 별도 승인 전에는 commit하지 않습니다.
